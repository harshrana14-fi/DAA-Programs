# Sorting Algorithms - DAA

This program implements the following sorting algorithms:

1. Bubble Sort
2. Insertion Sort
3. Merge Sort
4. Quick Sort

## Time Complexity Analysis

### 1. Bubble Sort

- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)
- Space Complexity: O(1)

### 2. Insertion Sort

- Best Case: O(n)
- Average Case: O(n²)
- Worst Case: O(n²)
- Space Complexity: O(1)

### 3. Merge Sort

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)
- Space Complexity: O(n)

### 4. Quick Sort

- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n²)
- Average Space Complexity: O(log n)
- Worst Case Space Complexity: O(n)

## Comparison Table

| Algorithm | Best Case | Average Case | Worst Case | Space |
|-----------|-----------|--------------|------------|-------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) average |

## Conclusion

Merge Sort provides O(n log n) time complexity in all cases.
Quick Sort is generally efficient but can have O(n²) worst-case complexity.
Bubble Sort and Insertion Sort are simple algorithms but are less efficient for large datasets.
